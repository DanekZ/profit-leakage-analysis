## Panduan screenshot

- Format PNG, lebar ±1600 px, tanpa area kosong di tepi.
- Nama file sesuai tabel di atas (dipakai oleh `README.md` utama).
- Bila ada tooltip atau slicer penting, ambil satu screenshot tambahan dengan akhiran `_filtered.png`.
